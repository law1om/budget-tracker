# Функции Budget Tracker

## 1. Аутентификация

### 1.1 Регистрация
**Тип:** Создание аккаунта  
**Действие:** Пользователь вводит имя, email и пароль (мин. 6 символов), нажимает "Зарегистрироваться"  
**Результат:** Создается аккаунт, выдается JWT токен, автоматический вход в систему, переход на главный экран

### 1.2 Вход
**Тип:** Авторизация  
**Действие:** Пользователь вводит email и пароль, нажимает "Войти"  
**Результат:** Проверка учетных данных, выдача JWT токена, загрузка данных пользователя, переход на главный экран

### 1.3 Выход
**Тип:** Завершение сеанса  
**Действие:** Пользователь в настройках нажимает "Выйти", подтверждает действие  
**Результат:** Удаление токена, очистка локальных данных, переход на экран приветствия

---

## 2. Управление транзакциями

### 2.1 Добавление расхода
**Тип:** Создание транзакции  
**Действие:** Пользователь нажимает FAB "+", выбирает тип "Расход", вводит сумму, выбирает категорию ( Еда,  Транспорт и т.д.), опционально вводит название, нажимает "Сохранить"  
**Результат:** Транзакция сохраняется в БД, баланс уменьшается на сумму расхода, транзакция появляется в списке на главном экране

### 2.2 Добавление дохода
**Тип:** Создание транзакции  
**Действие:** Пользователь нажимает FAB "+", выбирает тип "Доход", вводит сумму, выбирает категорию ( Зарплата,  Бизнес и т.д.), опционально вводит название, нажимает "Сохранить"  
**Результат:** Транзакция сохраняется в БД, баланс увеличивается на сумму дохода, транзакция появляется в списке

### 2.3 Редактирование транзакции
**Тип:** Изменение данных  
**Действие:** Пользователь долго нажимает на транзакцию, выбирает "Изменить", редактирует данные, нажимает "Обновить"  
**Результат:** Транзакция обновляется в БД, баланс пересчитывается, изменения отображаются в списке

### 2.4 Удаление транзакции
**Тип:** Удаление данных  
**Действие:** Пользователь долго нажимает на транзакцию, выбирает "Удалить", подтверждает удаление  
**Результат:** Транзакция удаляется из БД, баланс пересчитывается, транзакция исчезает из списка

### 2.5 Просмотр всех транзакций
**Тип:** Просмотр данных  
**Действие:** Пользователь на главном экране нажимает "Все" или переходит в раздел "История"  
**Результат:** Отображается полный список транзакций, отсортированный по дате (новые сверху)

---

## 3. Фильтрация и поиск

### 3.1 Фильтр по типу транзакции
**Тип:** Фильтрация  
**Действие:** Пользователь в истории выбирает фильтр "Доходы" или "Расходы"  
**Результат:** Отображаются только транзакции выбранного типа

### 3.2 Фильтр по периоду
**Тип:** Фильтрация по дате  
**Действие:** Пользователь выбирает "Фильтр по дате", указывает начальную и конечную дату, применяет фильтр  
**Результат:** Отображаются транзакции только за указанный период

### 3.3 Фильтр по категории
**Тип:** Фильтрация  
**Действие:** Пользователь выбирает конкретную категорию для просмотра  
**Результат:** Отображаются транзакции только выбранной категории

---

## 4. Статистика и аналитика

### 4.1 Просмотр статистики расходов
**Тип:** Визуализация данных  
**Действие:** Пользователь на главном экране нажимает "Статистика"  
**Результат:** Отображается круговая диаграмма расходов по категориям с процентным соотношением и суммами

### 4.2 Просмотр общей статистики
**Тип:** Просмотр сводки  
**Действие:** Пользователь просматривает карточку баланса на главном экране  
**Результат:** Отображается текущий баланс, общая сумма доходов, общая сумма расходов, количество транзакций

### 4.3 Просмотр недавних операций
**Тип:** Быстрый просмотр  
**Действие:** Пользователь на главном экране видит раздел "Недавние операции"  
**Результат:** Отображаются последние 10 транзакций с датой, категорией и суммой

---

## 5. Управление валютой

### 5.1 Смена валюты аккаунта
**Тип:** Конвертация  
**Действие:** Пользователь в настройках выбирает "Валюта", выбирает новую валюту (KZT/USD/EUR), подтверждает изменение  
**Результат:** Баланс конвертируется по текущему курсу, все транзакции конвертируются, все суммы отображаются в новой валюте

### 5.2 Добавление транзакции в другой валюте
**Тип:** Конвертация при создании  
**Действие:** Пользователь при добавлении транзакции выбирает валюту (KZT/USD/EUR), отличную от валюты аккаунта, вводит сумму  
**Результат:** Сумма автоматически конвертируется в валюту аккаунта по текущему курсу и сохраняется

### 5.3 Просмотр курсов валют
**Тип:** Информация  
**Действие:** Пользователь в экране конвертации видит актуальные курсы  
**Результат:** Отображаются текущие курсы конвертации между валютами

---

## 6. Настройки профиля

### 6.1 Изменение имени
**Тип:** Редактирование профиля  
**Действие:** Пользователь в настройках нажимает "Профиль", изменяет имя, сохраняет  
**Результат:** Имя обновляется в БД и отображается на главном экране

### 6.2 Изменение баланса
**Тип:** Корректировка баланса  
**Действие:** Пользователь в настройках изменяет начальный баланс  
**Результат:** Баланс обновляется, пересчитывается с учетом всех транзакций

### 6.3 Смена темы оформления
**Тип:** Настройка интерфейса  
**Действие:** Пользователь в настройках выбирает тему: Светлая/Темная/Системная  
**Результат:** Интерфейс приложения меняет цветовую схему согласно выбранной теме

### 6.4 Просмотр информации профиля
**Тип:** Просмотр данных  
**Действие:** Пользователь в настройках открывает "Профиль"  
**Результат:** Отображается имя, email, текущий баланс, валюта, тема оформления

---

## 7. Пагинация и производительность

### 7.1 Постраничная загрузка транзакций
**Тип:** Оптимизация загрузки  
**Действие:** Пользователь прокручивает список транзакций до конца  
**Результат:** Автоматически загружается следующая порция транзакций (50 шт.), список расширяется

### 7.2 Обновление данных (Pull-to-refresh)
**Тип:** Синхронизация  
**Действие:** Пользователь на главном экране или в истории тянет список вниз  
**Результат:** Данные обновляются с сервера, отображаются актуальные транзакции и баланс

---

## 8. Быстрые действия

### 8.1 Быстрое добавление через категорию
**Тип:** Ускоренное создание  
**Действие:** Пользователь на главном экране нажимает на карточку категории ( Еда,  Транспорт и т.д.)  
**Результат:** Открывается экран добавления транзакции с предвыбранной категорией и типом "Расход"

### 8.2 Переход к статистике
**Тип:** Быстрая навигация  
**Действие:** Пользователь на главном экране нажимает кнопку "Статистика"  
**Результат:** Открывается экран статистики с круговой диаграммой расходов

### 8.3 Переход к истории
**Тип:** Быстрая навигация  
**Действие:** Пользователь на главном экране нажимает кнопку "История" или "Все"  
**Результат:** Открывается экран истории со всеми транзакциями

---

## 9. Offline режим

### 9.1 Работа без интернета
**Тип:** Локальное хранение  
**Действие:** Пользователь работает с приложением при отсутствии интернета  
**Результат:** Данные читаются из локального кэша, новые транзакции сохраняются локально

### 9.2 Синхронизация при восстановлении соединения
**Тип:** Автоматическая синхронизация  
**Действие:** Интернет-соединение восстанавливается  
**Результат:** Локальные изменения автоматически отправляются на сервер, данные синхронизируются

---

## 10. Безопасность

### 10.1 Автоматический выход при истечении токена
**Тип:** Защита сеанса  
**Действие:** JWT токен истекает (по умолчанию через 24 часа)  
**Результат:** Пользователь автоматически выходит из системы, перенаправляется на экран входа

### 10.2 Защита данных
**Тип:** Авторизация запросов  
**Действие:** Пользователь выполняет любое действие с данными  
**Результат:** Все запросы к API отправляются с JWT токеном, доступ только к собственным данным
