# Budget Tracker

**Budget Tracker** — мобильное приложение для учета личных финансов, позволяющее пользователю отслеживать доходы и расходы, управлять категориями и анализировать финансовую активность.
---
## Стек технологий
- Flutter (Mobile)
- Spring Boot
- PostgreSQL
- JWT Authentication
- REST API
  
---
##Основные возможности

Подробное описание пользовательских сценариев и работы с приложением доступно здесь:  
**[How to use Budget Tracker](docs/how-to-use-budget-tracker.md)**

Кратко функционал включает:
- Регистрация и авторизация пользователей
- Добавление доходов и расходов
- Управление категориями
- Просмотр истории операций
- Аналитика и статистика расходов
- Облачное хранение данных
